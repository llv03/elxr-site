Docs

Commands, shortcuts, and core capabilities.

Quick start

  1. Create a new note with Cmd/Ctrl + N.
  2. Write in markdown and use split mode for live preview.
  3. Assign folders and tags for structure.
  4. Keep notes private, then toggle public only when needed.
  5. Copy share link for selected public notes.

Keyboard shortcuts

Shortcut Action
Cmd/Ctrl + N Create new note and choose folder
Cmd/Ctrl + F Open global search overlay
Cmd/Ctrl + K Open command palette
Cmd/Ctrl + S Force save current note

Capabilities

  • Create, edit, and delete markdown notes.
  • Organize notes with folders and tags.
  • Use tabs for multi-note workflows.
  • Switch between editor, split, and preview modes.
  • Toggle notes between private and public.
  • Generate share links for public notes.
  • Search notes globally and by active filters.
  • Open context menus for quick note and folder actions.

Platform snapshot

  • Desktop app: Tauri + React + TypeScript
  • Data: MongoDB
  • Share viewer: Read only markdown web endpoint
